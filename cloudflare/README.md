# Cloudflare Worker `woodlands-dumpster-rental-co`

This folder is exactly what is deployed to Cloudflare (Worker `woodlands-dumpster-rental-co`).
A push to `main` deploys it (`.github/workflows/deploy.yml`). Edit the site here: `public/` is the
published files, `api/` the endpoints. The Vercel-era files at the repo root are no longer deployed.
